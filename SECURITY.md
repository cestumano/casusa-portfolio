# Política de segurança

## Relatando uma vulnerabilidade

Não abra uma issue pública para vulnerabilidades ou exposição de dados.

Envie o relato de forma privada para `casusa.oliveiraneto@gmail.com`, incluindo:

- descrição do problema;
- passos mínimos para reproduzir;
- possível impacto;
- sugestão de correção, se houver.

O recebimento será confirmado assim que possível. Não explore a vulnerabilidade,
acesse dados de terceiros ou divulgue detalhes antes da correção.

## Escopo

Esta política cobre o código deste portfólio e sua configuração de publicação.
As obras, fotografias e textos são protegidos pelos direitos autorais indicados
em `COPYRIGHT.md`.
